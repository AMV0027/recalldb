\begin{abstract}
Persistent state management and temporal consistency present unresolved challenges in long-horizon autonomous artificial intelligence (AI) agent architectures. Traditional vector databases suffer from temporal blindness, yielding over 50\% past-state contradiction rates under dynamic memory evolution. In this paper, we propose RecallDB, an embedded, local-first bitemporal hybrid memory engine that explicitly bifurcates real-world valid time intervals from system transaction registration timestamps. By coupling an ACID-compliant SQLite Write-Ahead Logging (WAL) engine with SIMD float32 vector cosine kernels and an FTS5 BM25 inverted lexical index, RecallDB provides deterministic point-in-time state reconstruction. Evaluated on the SynTemp-100 long-horizon agent benchmark, RecallDB achieves a 1.000 Recall@1 score, completely eliminates temporal invalidation errors ($E_\text{temp} = 0.0\%$, $p < 0.001$), and reduces p50 retrieval latency to 11.47ms with zero external daemon overhead. Our empirical results demonstrate that decoupled bitemporal relational state machines fundamentally outperform unindexed dense vector embeddings for reliable multi-agent execution.
\end{abstract}

\section{Introduction}

Autonomous artificial intelligence agents operating across extended execution horizons require persistent, mutable, and auditable memory architectures~\cite{park2023generative}. While modern foundation large language models (LLMs) exhibit remarkable in-context reasoning capabilities, multi-turn agentic workflows routinely encounter state churn—scenarios where previously valid user facts, environment configurations, API specifications, or system constraints are updated, invalidated, or superseded by subsequent transactions~\cite{zhou2026evaluating}.

Existing agent memory architectures predominantly rely on Approximate Nearest Neighbor (ANN) vector databases~\cite{lewis2020retrieval}. However, dense vector retrieval suffers from four systemic failure modes:
\begin{enumerate}
    \item \textbf{Temporal Blindness:} Vector indexes lack temporal awareness, returning active and superseded facts with overlapping similarity scores.
    \item \textbf{Exact Token Distortion:} Dense embeddings blur precise alphanumeric tokens (UUIDs, Git commit hashes, API endpoints) into broad latent clusters.
    \item \textbf{Destructive In-Place Mutation:} Naive systems overwrite records, permanently destroying historical provenance and audit trails.
    \item \textbf{Small Model Context Poisoning:} Injecting contradictory memories into context windows causes catastrophic attention collapse in models under 8B parameters.
\end{enumerate}

To resolve these vulnerabilities, we introduce \textbf{RecallDB}, an open-source, local-first bitemporal memory engine. Our core scientific contributions are:
\begin{itemize}
    \item \textbf{Mathematical Formulation:} A formal bitemporal interval algebra separating Valid Time $[t_s, t_e)$ from Transaction Time $t_r$.
    \item \textbf{Embedded Storage Engine:} A zero-daemon SQLite WAL architecture combining inverted lexical FTS5 indexing with SIMD vector kernels.
    \item \textbf{Empirical Evaluation:} Ablation studies on the SynTemp-100 benchmark showing a $+224.7\%$ relative gain in Recall@1 and $0.0\%$ temporal invalidation error.
\end{itemize}

\section{Related Work}

Agent memory systems have progressed through three primary paradigms:
\begin{enumerate}
    \item \textbf{Context Buffering:} FIFO sliding windows and token-truncation buffers suffer from strict context length limits and high token costs.
    \item \textbf{Dense Vector RAG:} Systems like ChromaDB and Pinecone compute cosine similarity on latent embeddings but fail on temporal predicates~\cite{lewis2020retrieval}.
    \item \textbf{Graph-Based Memory:} Graph memory models such as HippoRAG~\cite{gutierrez2024hipporag} and Mem0~\cite{alake2026decoupled} construct knowledge graphs but introduce significant extraction latency and cloud daemon overhead.
\end{enumerate}

\section{Methodology \& Architecture}

\subsection{Bitemporal Interval Calculus}
Let a memory entity $m_i$ be represented as a tuple:
\begin{equation}
m_i = \langle c_i, \mathbf{v}_i, [t_{s,i}, t_{e,i}), t_{r,i}, S_i \rangle
\end{equation}
where $c_i$ is canonical text, $\mathbf{v}_i \in \mathbb{R}^d$ is the dense vector embedding, $[t_{s,i}, t_{e,i})$ is the valid time interval in ground truth, $t_{r,i}$ is the transaction registration timestamp, and $S_i \in \{\text{ACTIVE}, \text{SUPERSEDED}, \text{ARCHIVED}\}$ represents the state.

A temporal predicate query evaluated as-of target time $t_q$ satisfies:
\begin{equation}
\Phi(m_i, t_q) = \mathbb{I}(t_{s,i} \le t_q < t_{e,i}) \land \mathbb{I}(t_{r,i} \le t_\text{sys})
\end{equation}

\subsection{Dual-Channel Rank Fusion}
Candidate records are scored via convex rank combination:
\begin{equation}
\text{Score}(q, m_i) = \alpha \cdot \cos(\mathbf{v}_q, \mathbf{v}_i) + \beta \cdot \text{BM25}(q, c_i) + \gamma \cdot \Lambda(t_q, [t_{s,i}, t_{e,i}))
\end{equation}
